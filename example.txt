# ===== 道岔定义（名称 初始位置） =====
道岔 P1 定位
道岔 P2 定位
道岔 P3 反位

# ===== 信号机定义 =====
信号机 X1
信号机 X2
信号机 X3

# ===== 进路定义（名称 区段列表 所需道岔位置 信号机） =====
进路 R1 区段=G1,G2,G3 道岔=P1:定位,P2:反位 信号机=X1
进路 R2 区段=G3,G4 道岔=P2:定位 信号机=X2
进路 R3 区段=G5,G6 道岔=P3:反位 信号机=X3
进路 R4 区段=G7 信号机=X9          # 引用不存在的信号机（定义错误）

# ===== 操作流 =====
排列 R1                            # P2 未在反位 -> 道岔未转到位
转换道岔 P2 反位
排列 R1                            # 成功，X1 开放
排列 R2                            # 与 R1 共享 G3 -> 敌对进路拦截
排列 R3                            # 成功，X3 开放
排列 R3                            # 重复排列 -> 报错
取消 R2                            # 未排列 -> 报错
转换道岔 P1 反位                   # R1 级联失效，X1 关闭
排列 R9                            # 进路不存在 -> 报错
转换道岔 P9 定位                   # 道岔不存在 -> 报错
取消 R1                            # 已级联失效 -> 取消未排列报错
排列 R4                            # 信号机不存在 -> 报错
取消 R3                            # 成功，X3 关闭
